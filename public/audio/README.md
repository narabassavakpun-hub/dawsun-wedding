# วางไฟล์เพลงที่นี่

เว็บมองหาไฟล์ชื่อ **`theme.mp3`** ในโฟลเดอร์นี้

```
public/audio/theme.mp3
```

ถ้าไม่มีไฟล์ ปุ่มเล่นเพลงมุมขวาล่างจะยังขึ้น แต่กดแล้วไม่มีเสียง (เว็บส่วนอื่นทำงานปกติ)

---

## ข้อกำหนดไฟล์

| | |
|---|---|
| ชื่อไฟล์ | `theme.mp3` (ต้องตรงเป๊ะ ตัวพิมพ์เล็ก) |
| รูปแบบ | MP3 |
| ความยาว | 3–4 นาที (เว็บเล่นวนซ้ำอัตโนมัติ) |
| ขนาด | ไม่เกิน 4 MB — ถ้าใหญ่กว่านี้แขกที่เน็ตช้าจะโหลดนาน |
| Bitrate แนะนำ | 128 kbps mono หรือ 160 kbps stereo (พอสำหรับเพลงพื้นหลัง) |

---

## หาเพลงบรรเลง royalty-free ได้ที่ไหน

เลือกเพลงบรรเลง **เปียโน** หรือ **กีตาร์ acoustic** โทนอบอุ่นนุ่มนวล
ให้อารมณ์ใกล้เคียง *At My Worst* ของ Pink Sweat$

| แหล่ง | ลิงก์ | หมายเหตุ |
|---|---|---|
| Pixabay Music | pixabay.com/music | ฟรี ไม่ต้องให้เครดิต ดาวน์โหลดตรงเป็น mp3 |
| YouTube Audio Library | youtube.com/audiolibrary | ฟรี กรองเฉพาะเพลงที่ "ไม่ต้องระบุแหล่งที่มา" |
| Uppbeat | uppbeat.io | free tier ต้องสมัครและใส่เครดิต |
| Chosic | chosic.com/free-music | รวมเพลง Creative Commons |

**คำค้นที่ใช้ได้ผล** — `romantic piano`, `soft acoustic love`, `wedding instrumental`,
`gentle guitar ballad`, `dreamy piano`

---

## ทำไมไม่ใช้เพลง At My Worst ตัวจริง

เพลงต้นฉบับมีลิขสิทธิ์ การอัปโหลดไฟล์ขึ้นเว็บสาธารณะบน GitHub Pages
เข้าข่ายการเผยแพร่ต่อสาธารณะ ซึ่งอาจถูกแจ้งลบหรือทำให้ repo ถูกระงับได้
เพลงบรรเลงที่อารมณ์ใกล้เคียงกันให้ผลลัพธ์ที่ดีพอๆ กันโดยไม่มีความเสี่ยง
